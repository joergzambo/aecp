Subnetting und VLSM

Ein großes Netz wird in kleinere Subnetze geteilt – entweder gleich groß (klassisches Subnetting) oder genau so groß, wie jede Gruppe es braucht (VLSM, Variable Length Subnet Mask). Dabei sollen so wenig Adressen wie möglich verschwendet werden.

Regelwerk

Wie viele Adressen?

  • In jedem Subnetz gehen 2 Adressen weg: die Netzadresse (alle Hostbits 0) und die Broadcastadresse (alle Hostbits 1).
  • Nutzbare Hosts = 2h − 2 (h = Anzahl Hostbits).
  • Suche das kleinste h mit 2h − 2 ≥ Clients. Präfix = 32 − h.
  • Vorsicht bei Grenzfällen: 30 Clients → /27 (30 Hosts), aber 31 Clients → /26!

Netz- und Broadcastadresse

  1. Das interessante Oktett suchen – dort, wo die Maske weder 255 noch 0 ist.
  2. Blockgröße = 256 − Maskenwert in diesem Oktett (z. B. 256 − 224 = 32).
  3. Netzadresse = größtes Vielfaches der Blockgröße ≤ dem Wert der IP.
  4. Broadcast = nächste Netzadresse − 1. Dahinter alles 255.
  5. Erster Host = Netz + 1, letzter Host = Broadcast − 1.

VLSM-Rezept

  1. Für jede Gruppe die Größe bestimmen (2h).
  2. Nach Größe sortieren – das größte Netz zuerst. Dann landet jedes Netz automatisch auf einer passenden Grenze.
  3. Am Anfang des gegebenen Netzes beginnen und lückenlos vergeben: nächste Netzadresse = Broadcast + 1.
  4. Für Router-Verbindungen (2 Adressen) reicht ein /30.

Supernetting

Beim Supernetting (Route Summarization) fasst man mehrere Netze zu einem größeren zusammen. Statt vier Routen genügt dann eine – die Routing-Tabelle wird kleiner. Der Trick: die Netze binär untereinander schreiben und schauen, wie viele Bits von links gleich sind.

Regelwerk

Das Rezept

  1. Alle Netze binär untereinander schreiben – oft reicht das Oktett, in dem sie sich unterscheiden.
  2. Von links die Bits zählen, die bei allen gleich sind. Das ist das neue Präfix.
  3. Die gleichen Bits übernehmen, den Rest auf 0 setzen – das ist die Netzadresse der Zusammenfassung.
  4. Bei Netzen mit verschiedener Größe zählt auch das Ende (Broadcast) des letzten Netzes mit.

Schnell im Kopf

  • 2 Netze → 1 Bit weniger, 4 Netze → 2 Bits, 8 Netze → 3 Bits …
  • Das klappt aber nur, wenn das erste Netz auf einer passenden Grenze liegt: 4 × /24 ab einem Vielfachen von 4 im 3. Oktett.
  • 192.168.4.0 – 192.168.7.0 → 192.168.4.0/22.

Vorsicht: zu viel zusammengefasst

  • Liegen die Netze nicht schön auf einer Grenze, wird die Zusammenfassung größer und enthält Adressen, die es gar nicht gibt.
  • Beispiel: 192.168.3.0/24 und 192.168.4.0/24 → erst 192.168.0.0/21 umfasst beide – das sind 8 Netze statt 2.
  • Ein Router schickt dann auch Pakete für die „fremden“ Netze dorthin.

Wofür?

  • Eine statische Route statt vieler: ip route 192.168.4.0 255.255.252.0 10.0.0.2
  • Kleinere Routing-Tabellen, weniger Updates bei Routing-Protokollen.
  • Supernetting ist das Gegenteil von Subnetting: Bits werden dem Hostteil dazugegeben statt weggenommen.
