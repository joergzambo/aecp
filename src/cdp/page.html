CDP – Nachbarn erkennen und den Netzplan rekonstruieren

Das Cisco Discovery Protocol verrät, welches Cisco-Gerät an welchem Port hängt – mit Hostname, Modell, IP-Adresse und Software-Version. Damit kann man ein unbekanntes Netz Stück für Stück aufzeichnen.

Eine CDP-Ausgabe lesen

Der Befehl wurde auf KERN eingegeben. Klick auf eine Zeile der Ausgabe – dann siehst du, welches Kabel sie beschreibt und was in der Detail-Ausgabe dazu steht.

KERN# show cdp neighbors


 
Jede Zeile ist ein direkt verbundener Nachbar – also ein Kabel. Klick auf eine Zeile.

 
KERN# show cdp neighbors detail (nur dieser Nachbar)
Klick oben auf eine Zeile.





Wissen und Befehle



 
Was ist CDP?
    
  
  • Cisco-eigenes Protokoll auf Layer 2 – funktioniert auch ohne IP-Konfiguration.
    • 
  
  • Zeigt nur direkt verbundene Cisco-Geräte. Was hinter dem Nachbarn liegt, sieht man nicht.
    • 
  
  • Standardmäßig an, alle 60 Sekunden ein Paket, ein Eintrag gilt 180 Sekunden (Holdtime).
    • 
  
  • Die herstellerneutrale Alternative ist LLDP (IEEE 802.1AB).

 
Die zwei Ports einer Zeile
    
  
  • Local Intrfce = der Port am eigenen Gerät, auf dem der Befehl läuft.
    • 
  
  • Port ID = der Port am Nachbarn.
    • 
  
  • In der Detail-Ausgabe heißen sie Interface und Port ID (outgoing port).

  
Häufigster Fehler: die beiden vertauschen.

 
Modell und IP-Adresse
    
  
  • In show cdp neighbors ist die Platform-Spalte abgeschnitten (WS-C2960-). Das volle Modell steht nur in detail.
    • 
  
  • Die IP-Adresse gibt es nur in detail (Entry address).
    • 
  
  • Ein Switch meldet seine Management-IP (SVI). Ein Router meldet die IP des Interfaces, über das das CDP-Paket hinausgeht – jedem Nachbarn also eine andere.
    • 
  
  • Ist eine Domain konfiguriert, steht sie in der Device ID: ZEUS.htl.local ist das Gerät mit dem Hostname ZEUS.

 
Sicherheit
    
  
  • CDP verrät Modell, IOS-Version und IP-Adressen – wertvoll für Angreifer.
    • 
  
  • An Ports zu fremden Geräten, Gästen und zum Internet abschalten.
    • 
  
  • CDP-Pakete sind nicht authentifiziert und lassen sich fälschen.






BefehlWas er macht


show cdp neighborsKurzliste aller Nachbarn: Device ID, eigener Port, Holdtime, Fähigkeiten, Plattform (abgeschnitten), Port am Nachbarn


show cdp neighbors detailAlles pro Nachbar: IP-Adresse, volles Modell, beide Ports, IOS-Version, Native VLAN, Duplex


show cdp entry ZEUSDetails nur für einen Nachbarn


show cdp interfaceAuf welchen Interfaces CDP läuft, Timer


no cdp run / cdp runCDP auf dem ganzen Gerät aus- bzw. einschalten (global)


interface g0/1 → no cdp enableCDP nur auf einem Interface abschalten


lldp run, show lldp neighborsLLDP einschalten (bei Cisco standardmäßig aus) und Nachbarn anzeigen

Übungen


Die Geräte und ihre Ports sind aufgezeichnet – aber nicht verkabelt. Lies die CDP-Ausgaben und finde für jedes Gerät Modell und IP-Adresse. Dann steck die Kabel: erst auf einen Port klicken, dann auf den Port am anderen Ende. Ein Klick auf ein Kabel zieht es wieder ab. Nicht jeder Port wird gebraucht.
